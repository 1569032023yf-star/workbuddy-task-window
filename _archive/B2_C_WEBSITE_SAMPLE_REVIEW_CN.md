## 七、产品适配判断标准

本次核实使用以下标准判断是否适合 rokt&razo：

### 适合 ✅
- 网站卖 board games / tabletop games / card games
- 网站卖 toys / educational toys
- 网站卖 puzzles / jigsaw puzzles
- 网站是 gift shop / museum store / bookstore gift section
- 网站有 wholesale / vendor / product submission 页面
- 门店位于旅游小镇 / 大学城 / 小城市 / 富人郊区
- 商品结构适合 family games / jigsaw puzzles / gifts

### 不适合 ❌
- 核心业务为漫画书（comic books）而非桌游/拼图
- 旅游纪念品店（非玩具/游戏类）
- 店铺已关闭
- 网站已下线
- 餐厅/酒吧为主（非零售）
