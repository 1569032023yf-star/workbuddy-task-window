# 2026-07-20 Work Log (update)

## Inventory 启动故障修复

### 根因
- **#1 数据库陈旧锁**: `run_lock:daily_outreach:inventory:2026-07-20` 因之前 dry-run 崩溃从未释放，导致后续 --live 运行在 acquire_run_lock 处立即退出
- **#2 文件陈旧锁**: `output\.inventory_recovery.lock` PID 1361 已失效
- **#3 陈旧 job_run**: `job_runs` 表中旧记录 status='running' 阻止新记录创建
- **#4 PowerShell $pid 变量冲突**: `inventory_recovery_runner.ps1` 用 `$pid` 覆盖了 PowerShell 自动变量 `$PID`

### 修复
1. **bd_orchestrator.py**: stage_inventory 加 try/finally 确保 lock 释放
2. **bd_db.py**: acquire_run_lock + start_job_run 加 2h 陈旧锁自动检测
3. **inventory_recovery_runner.ps1**: `$pid` → `$storedPid`，`$PID` → `[System.Diagnostics.Process]::GetCurrentProcess().Id`
4. **bd_orchestrator.py**: 加 SIGPIPE 保护
5. 清理所有陈旧锁和 job_runs
