## Closed-Loop BD Email System (2026-06-11)

### Task
建立完整闭环：线索收集 → 邮件草稿 → 发信队列 → 小批量发送 → 回复/退信/退订记录 → 状态更新

### System Built
```
bd_db.py        — 闭环数据库 (leads + suppression_list + send_log)
bd_sender.py    — 腾讯企业邮箱 SMTP (465/SSL)，从 .env 读取
bd_template.py  — 确认的邮件模板
bd_main.py      — 主入口 (status/approve-all/dry-run/test-send/send)
env_loader.py   — .env 配置加载器
.env            — SMTP 配置 (密码已配置，邮箱地址待填写)
.gitignore      — 排除 .env 和数据库
```

### Pipeline Commands
- `python bd_main.py status` — 查看系统状态
- `python bd_main.py approve-all` — 批准 A/B 级线索
- `python bd_main.py dry-run` — 预览将发送的邮件
- `python bd_main.py test-send` — 发送到测试邮箱
- `python bd_main.py send` — 实际发送
